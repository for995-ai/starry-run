# 星空探險 Starry Run｜路跑活動報名網站

路跑活動官方網站原型，涵蓋活動介紹、線上報名、組別選擇與結帳流程。

## Overview

本專案為路跑活動的活動官網與報名流程原型，包含活動說明、賽事資訊、
報名表單、組別與加購商品選擇，以及結帳頁面。

網站承接 2026 全球品牌大賽高雄初賽的活動企劃。

## Features

- 活動介紹與賽事資訊頁
- 線上報名表單
- 組別選擇與費用試算
- 加購商品（跑衣、毛巾、獎牌）選擇
- 結帳流程與完成頁
- 志工報名區塊
- 響應式版面

## Demo Mode（重要）

**此 GitHub Pages 版本為作品集展示用途，採用 Demo Mode：**

- 報名與結帳流程**不會**送出任何資料到任何線上服務
- **不蒐集、不儲存身分證字號**（展示版本已移除該欄位）
- 送出後僅顯示「作品集展示模式：資料未實際送出」並進入完成頁
- 表單內容僅暫存於瀏覽器本機，不會離開你的裝置

This portfolio demo uses mock submission and does not store personal information.
